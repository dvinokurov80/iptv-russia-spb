# IPTV Russia + Saint Petersburg

Единый автоматически обновляемый M3U-плейлист для Televizo и OTT Navigator.

## Принципы отбора

- Бесплатные публично доступные IPTV-потоки; каналы, требующие платной подписки или учётных данных, не добавляются.
- Федеральные и общероссийские каналы собраны в категорию «Общероссийские». Фильмы и сериалы объединены в одну категорию; познавательные каналы включают науку, документалистику, путешествия, рыбалку, природу и похожие темы. Развлекательные каналы не смешиваются с фильмами и сериалами. Детские, религиозные и спортивные каналы исключены.
- Местные каналы Санкт-Петербурга и Ленинградской области также включаются.
- Местные каналы других регионов России исключаются.
- Для каждого телеканала оставляется одна запись — выбирается поток с наилучшим заявленным качеством. Дубли SD/HD/Full HD не создаются.
- Для потока в базе источника должна быть указана зона вещания, подходящая под критерии, и часовой пояс Europe/Moscow без других часовых поясов. Региональные версии с временным сдвигом не включаются.
- Категории: «Общероссийские», «Фильмы и сериалы», «Познавательные», «Развлекательные», «Музыка» и «Санкт-Петербург и Ленобласть». Отдельной спортивной категории нет — спортивные телеканалы исключаются. НТВ Хит и НТВ Сериал относятся к «Фильмам и сериалам», НТВ Стиль — к «Развлекательным». Т24, «Наука 2.0», каналы о путешествиях, рыбалке и природе относятся к «Познавательным». Избранное — дополнительная категория с повторными записями для удобства навигации.
- Исключаются детские, религиозные и спортивные каналы, а также каналы с EPG-метаданными, где указана только украинская телепрограмма. Категория «Для взрослых» пока не опубликована: в неё будут добавляться только проверенные открытые потоки с подтверждённым источником вещания, без чужих платных подписок, временных ключей и учётных данных.

Состав формируется из общероссийского списка iptv-org, отдельного списка каналов НТВ, двух дополнительных российских публичных плейлистов (ngrch и gdydg), а также списков Санкт-Петербурга и Ленинградской области. Дополнительные списки используются для обнаружения каналов, которых может не быть в основном российском файле; они проходят те же проверки и не принимаются автоматически. Для фильтрации используются метаданные каналов и потоков iptv-org: территория вещания, часовой пояс, категория и заявленное качество.

## Телепрограмма

В заголовке M3U указан XMLTV-гид iptvX|one (с актуальными данными по российским каналам):
`https://iptvx.one/EPG`

Сборщик поддерживает gzip, загружает XMLTV при каждой сборке и сопоставляет каналы по ID, для которых в программе действительно есть передачи. Если точный ID не совпадает, выполняется осторожное сопоставление по названию: принимается только уникальное совпадение, причём один EPG-ID не назначается нескольким каналам. В журнале GitHub Actions выводится число точных совпадений, совпадений по названию и каналов без подтверждённой программы.

По данным страницы проекта iptvX|one, программа обновляется и включает архив и описания передач. Фактическое покрытие всё равно зависит от конкретного телеканала и доступности его телепрограммы.

## Автообновление

GitHub Actions обновляет плейлист ежедневно в 06:17 по московскому времени и при изменении скрипта сборки. Перед публикацией проверяются структура M3U, минимальное количество уникальных каналов и отсутствие дублей вне категории «Избранное».

Публичная ссылка остаётся постоянной. Наличие открытого URL не гарантирует непрерывную работу потока: вещатель или хостинг может изменить адрес, ограничить доступ или отключить трансляцию.
