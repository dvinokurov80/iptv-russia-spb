# IPTV Russia + Saint Petersburg

Единый M3U-плейлист для Televizo и OTT Navigator.

Проект предназначен для российских федеральных телеканалов и местных телеканалов Санкт-Петербурга. Плейлист будет собираться автоматически из открытых источников и обновляться через GitHub Actions.

## Файлы

- `playlist.m3u` — итоговый плейлист для приложений IPTV.
- `build_playlist.py` — сборка плейлиста.
- `.github/workflows/update.yml` — ежедневное автоматическое обновление.

После настройки итоговый адрес плейлиста:

`https://raw.githubusercontent.com/dvinokurov80/iptv-russia-spb/main/playlist.m3u`

Проверка EPG и состава каналов будет выполнена отдельно перед публикацией рабочего плейлиста.
