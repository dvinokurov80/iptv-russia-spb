# IPTV Russia + Saint Petersburg

Единый автоматически обновляемый M3U-плейлист для Televizo и OTT Navigator.

## Принципы отбора

- Бесплатные публично доступные IPTV-потоки; каналы, требующие платной подписки или учётных данных, не добавляются.
- Общероссийские российские телеканалы всех доступных тематик: новости, спорт, кино, сериалы, музыка, развлечения, познавательные, детские и другие.
- Местные каналы Санкт-Петербурга и Ленинградской области также включаются.
- Местные каналы других регионов России исключаются.
- Для каждого телеканала оставляется одна запись — выбирается поток с наилучшим заявленным качеством. Дубли SD/HD/Full HD не создаются.
- Для потока в базе источника должна быть указана зона вещания, подходящая под критерии, и часовой пояс Europe/Moscow без других часовых поясов. Региональные версии с временным сдвигом не включаются.
- Каналы распределяются по русскоязычным категориям. Избранное — дополнительная категория; её записи повторяют выбранные каналы только для удобства навигации.

Состав формируется из общероссийского списка, а также списков Санкт-Петербурга и Ленинградской области. Для фильтрации используются метаданные каналов и потоков iptv-org: территория вещания, часовой пояс, категория и заявленное качество.

## Телепрограмма

В заголовке M3U указан русскоязычный EPG:
`http://epg.one/ru.xml.gz`

Совпадение EPG проверяется по идентификаторам каналов; фактическое наличие программы зависит от покрытия EPG-провайдера.

## Автообновление

GitHub Actions обновляет плейлист ежедневно в 06:17 по московскому времени и при изменении скрипта сборки. Перед публикацией проверяются структура M3U, минимальное количество уникальных каналов и отсутствие дублей вне категории «Избранное».

Публичная ссылка остаётся постоянной. Наличие открытого URL не гарантирует непрерывную работу потока: вещатель или хостинг может изменить адрес, ограничить доступ или отключить трансляцию.
