# IPTV Russia + Saint Petersburg

Единый M3U-плейлист для Televizo и OTT Navigator.

Проект собирает выбранные федеральные российские телеканалы и каналы Санкт-Петербурга. Другие региональные подборки не добавляются.

## Категории

- Избранное
- Фильмы
- Музыка
- Развлекательные
- Познавательные
- Новости
- Спорт
- Детские
- Санкт-Петербург — региональные каналы, для которых не удалось определить жанр

Каналы из «Избранного» также остаются в своих основных тематических категориях.

## Файлы

- `playlist.m3u` — итоговый плейлист.
- `build_playlist.py` — сборка и распределение каналов по категориям.
- `.github/workflows/update.yml` — ежедневное автоматическое обновление.

## Адрес плейлиста

После успешной первой сборки:

`https://raw.githubusercontent.com/dvinokurov80/iptv-russia-spb/main/playlist.m3u`

EPG-источник указан в заголовке M3U. Совместимость и соответствие телепрограммы каналам необходимо проверить после первой сборки.


Последняя настройка автоматизации: сборка запускается при изменении исходников, ежедневно по расписанию или вручную через GitHub Actions.
