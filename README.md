# IPTV Russia + Saint Petersburg

Единый самообновляемый M3U-плейлист для Televizo и OTT Navigator.

В плейлист включены отобранные федеральные российские телеканалы и каналы из регионального списка Санкт-Петербурга. Региональные списки других субъектов РФ не подключаются.

«Пятый канал» — федеральный вещатель, штаб-квартира и эфирное вещание которого находятся в Санкт-Петербурге; отдельный независимый петербургский телеканал с таким названием не выделяется. Для него используется публичный HLS-поток. Канал «78» пока не включён: официальный сайт публикует веб-плеер, но пригодный для IPTV-плееров открытый M3U/HLS-адрес подтвердить не удалось. Официальный эфир «78»: https://78.ru/tv.

## Категории

- Избранное
- Фильмы
- Музыка
- Развлекательные
- Познавательные
- Новости
- Спорт
- Детские
- Санкт-Петербург

Избранные каналы также остаются в своих основных категориях.

## Телепрограмма

В заголовке M3U прописан русскоязычный EPG от EPG.ONE:
`http://epg.one/ru.xml.gz`

## Автообновление

GitHub Actions обновляет плейлист ежедневно в 06:17 по московскому времени, а также при изменении скрипта сборки. Плеер использует постоянную ссылку выше.

Состав потоков и доступность отдельных каналов могут меняться на стороне исходных вещателей.
